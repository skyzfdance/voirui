# 规则：禁止修改全局环境变量

## 禁止行为
- 禁止修改 `~/.zshrc` 文件
- 禁止修改 `~/.bashrc` 文件
- 禁止修改 `~/.bash_profile` 文件
- 禁止修改 `/etc/profile` 文件
- 禁止修改 `/etc/zshrc` 文件
- 禁止修改任何全局 shell 配置文件

## 禁止的修改类型
- 添加、删除或修改 `export` 语句
- 修改 `PATH` 环境变量
- 添加别名（`alias`）
- 修改 `ZSH_THEME` 或其他主题配置
- 添加插件或源（`source`）其他脚本

## 替代方案
如需修改 shell 环境：
1. 在项目本地使用 `.env` 文件
2. 使用项目特定的配置文件
3. 在 IDE/编辑器设置中配置环境变量

## 原因
修改全局环境变量可能导致：
- 系统不稳定或其他应用冲突
- 难以追踪的副作用
- 团队协作时的环境不一致
- 潜在的系统安全风险
